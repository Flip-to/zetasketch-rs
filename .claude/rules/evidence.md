# Evidence for Every Claim

Applies to: everything written for others: docs (specs, findings, decisions, tech debt, runbooks),
PR bodies, review comments and replies, commit messages, bean bodies, code comments that state a fact or a number.

## Rules

1. **No evidence, no claim.** Not measured or not read: write it as a question, or say "not measured" / "not verified" and what would verify it.
2. **Evidence is dated.** Cite the file:line, test name, commit SHA, or date run.
3. **Agent claims are claims.** "Done", "fixed", "verified" from an agent moves nothing until the check behind it is shown.
4. **Corrections stay visible.** A claim found wrong is corrected in the open (the PR's Corrections section, a superseding decision), not silently edited away.
